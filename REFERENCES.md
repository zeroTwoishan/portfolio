# References

UI and portfolio references for the new portfolio. Take patterns and feel from these, not assets: borrow a layout idea or an interaction, and check the license before reusing anyone's component code or sounds.

| Reference | What to take from it |
| --- | --- |
| [shwn.design](https://shwn.design) | A clean, near-white page with a one-line, first-person intro, and work shown as small tactile objects (a Walkman, a TV, a dial, a vinyl) |
| [bencho.dev](https://bencho.dev) | Live React micro-interactions (slide to confirm, tilt card, magnetic select, reorder list) and a collection of UI sounds |
| [motion.dev](https://motion.dev) | Motion, the React animation library (formerly Framer Motion), for spring and exit animations |
| [dribbble.com](https://dribbble.com) | Shots for "developer portfolio" and "personal website" layouts, palettes and type |
| [designbookmark.com](https://designbookmark.com) | A directory of 2,500+ design tools. Its portfolio galleries (Killer Portfolio, Wall of Portfolios), OG Image Design and Color Review are the useful ones |
| [guptakaran0720.vercel.app](https://guptakaran0720.vercel.app/) (a friend's site) | Work grouped as "one door per field" cards (AI, mobile, distributed, full stack), a numbered story timeline, a "by the numbers" strip (PRs, commits, LeetCode rating), skills grouped by area, an "Open to work" badge and a résumé button in the hero |
| [react-three-fiber](https://github.com/pmndrs/react-three-fiber) | React renderer for three.js. Not used in DARKROOM v1 (the plan chose SVG, then plain three.js after launch). Consider it if a future project has several 3D scenes. |
| [liquid-glass-js](https://github.com/dashersw/liquid-glass-js) | Apple-style "liquid glass" refraction for UI. Off-brand for DARKROOM (no glassmorphism). Ideas only; check the license before reusing code. |
| [shadergradient](https://github.com/ruucm/shadergradient) | Animated WebGL gradient backgrounds (React/Framer). Off-brand for DARKROOM v1 (no gradients, no extra WebGL). |
| [liquid-logo](https://github.com/collidingScopes/liquid-logo) | Turns a logo into a liquid-metal shader animation. A possible post-launch idea for a metallic aperture glyph. Check the license. |
| [spline.design](https://spline.design) | Browser 3D design tool with a web embed. Avoid for DARKROOM: the runtime is heavy. |
| [shaders.com](https://shaders.com/) | Shader effects and examples. Grain, light and distortion ideas. |
| [framer.com](https://www.framer.com/) | Site builder with good motion and layout examples to study. |
| [freefaces.gallery](https://www.freefaces.gallery/) | Free display typefaces. Check each font's license before use. |
| [bookofshapes.com](https://bookofshapes.com/) | Free shape and SVG library. Useful for the mark glyphs and favicon; check the license terms. |
| [recent.design](https://recent.design/) | Curated feed of recent web design, for layout and type ideas |
| [Mudit OS](https://github.com/Mudit13-tech/PORTFOLIO) (a friend's site, source code) | Every count derived from the data and never hardcoded, a plain HTML version for no-JS visitors and crawlers, a "failures" section tied to real commits, a build-time OG image, and separate desktop and phone layouts over one content layer. No license: read it for ideas, don't copy its code |
